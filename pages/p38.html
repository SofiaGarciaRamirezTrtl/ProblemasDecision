🏆 Problema 3.8

Bono del Trabajador

Calcula el bono según antigüedad (≥ 5 años → 20%) o sueldo (≥ $10,000 → 15%).

📝 Ingresar Datos
Bono Calculado
💻 Pseudocódigo
Pseudocódigo — 3.8
INICIO

  LEER nombre, antiguedad, sueldo

  SI antiguedad >= 5 ENTONCES
    bono ← sueldo * 0.20
    motivo ← "Antigüedad ≥ 5 años (20%)"
  SINO SI sueldo >= 10000 ENTONCES
    bono ← sueldo * 0.15
    motivo ← "Sueldo ≥ $10,000 (15%)"
  SINO
    bono ← 0
    motivo ← "No cumple condiciones"
  FIN SI

  ESCRIBIR "Bono: $" + bono + " — " + motivo

FIN
