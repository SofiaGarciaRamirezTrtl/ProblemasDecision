👥 Problema 3.5

Menor Edad entre Tres Personas

Compara las edades de tres personas y determina cuál tiene la menor.

📝 Ingresar Datos
Persona de Menor Edad
📊 Diagrama de Flujo
💻 Pseudocódigo
Pseudocódigo — 3.5
INICIO

  LEER nombre1, edad1
  LEER nombre2, edad2
  LEER nombre3, edad3

  SI edad1 <= edad2 Y edad1 <= edad3 ENTONCES
    menor ← nombre1
    edadMenor ← edad1
  SINO SI edad2 <= edad1 Y edad2 <= edad3 ENTONCES
    menor ← nombre2
    edadMenor ← edad2
  SINO
    menor ← nombre3
    edadMenor ← edad3
  FIN SI

  ESCRIBIR "La persona de menor edad es: " + menor
  ESCRIBIR "Edad: " + edadMenor

FIN
🗂️ Diagrama N/S
Leer: nombre1,edad1 / nombre2,edad2 / nombre3,edad3
edad1 ≤ edad2 Y edad1 ≤ edad3
